This also caught and fixed a pre-existing bug unrelated to this PR's feature work:
tsconfig.json's rootDir "." + include ["src","prisma","tests"] made `tsc` emit to
dist/src/server.js, not dist/server.js, so "start": "node dist/server.js" had never
actually run successfully. Fixed by adding tsconfig.build.json (rootDir/include
narrowed to "src") used by the `build` script, and a new `typecheck` script
(tsc -p tsconfig.json --noEmit) that keeps the original full type-check coverage
over tests/ and prisma/ without emitting them into the production image.
